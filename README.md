# KURAGE FC

Advanced STM32H743 Flight Controller Technologies for UAV, Robotics, Autonomous Systems, and Defense Applications.

Official Website: https://fukushima-gk.com/custom-fc/

Company: FUKUSHIMA LLC

---

## Overview

KURAGE FC is a custom flight controller development program focused on STM32H743-based autopilot hardware, ArduPilot integration, PX4 integration, MAVLink systems, companion computer architectures, and mission-critical UAV electronics.

The platform supports fixed-wing UAVs, VTOL aircraft, multirotors, autonomous robotic systems, and custom embedded platforms.

KURAGE FC is part of the KURAGE Tactical Systems product family developed by FUKUSHIMA LLC.
